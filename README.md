# Crazy Shooters RPG

A browser-based original 3D arena FPS inspired by the fast gameplay of classic web shooters.

## Controls
- WASD — move
- Mouse — aim
- Left click — shoot
- R — reload
- Shift — sprint
- Space — jump

## Features
- 3D first-person gameplay
- Enemy bots
- Shooting and reload system
- HP and death
- Kills, money and XP
- RPG levels with automatic upgrades
- Arena with cover

The project uses Three.js from jsDelivr.
